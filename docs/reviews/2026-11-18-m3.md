## 4. Decisions

- **R2-1 is high and blocking** although no reported number of the documented workflows changes today: the reserved 2025+ Yahoo window can be confirmed only once, and a test that rejects 8 to 20% of the time under a nominal 5% would spend it on weak evidence.
- **REVIEW-58 and REVIEW-62 block ROBUST-01, not STATS-01:** null simulations need neither market identities nor corporate actions, while data and universe perturbations need both.
- **Lowering `--n-trials` without search evidence stays allowed,** as the user chose for the K8 remainder; only README.md's wording changes.
- **No new run record:** the replay reproduces the record's dataset hashes and the documented current-code figures, so nothing in it is unexplained. A new record of the same snapshot is worth making once the blocking fixes are merged (it would also carry the quantile portfolios the 2026-10-07 record lacks).
- **No refactor:** every class fix above changes behavior (a shared check, a refusal, a recorded identity), so each is a fix, not a refactor; nothing calls for a behavior-preserving restructuring.
- **The checkpoint waited six weeks** after it was first flagged (2026-10-07), but no feature started in that time, so §11 was followed; the staged fixes ran first by the agreed order.

## 5. Guideline changes

Proposed in a separate commit of this pull request, so they can be taken or dropped on their own:

1. **Fix the class by the broken assumption** ([GIT_GUIDELINES.md](../../GIT_GUIDELINES.md#before-marking-ready), Before marking ready step 3): name the assumption the defect broke and search every component for code that relies on it, not only for the same code pattern. Escape: #19 (E1, E2).
2. **Check a declared property where it is relied on** ([DESIGN_BY_CONTRACT.md](../../DESIGN_BY_CONTRACT.md#4-repository-contracts) §4): a consumer that relies on a declared property of its input (bar frequency, price adjustment, availability time, market identity) checks it through the shared reader of that kind, and a producer checks any property it declares that the data can show. Escapes: E2, R1-1, R1-2, R1-4.
3. **Test with inputs that break the convenient assumptions** ([PYTHON_GUIDELINES.md](../../PYTHON_GUIDELINES.md#testing-strategy), Testing strategy): code that reads prices is tested with a dated split and dividend (as-traded close unlike the adjusted close), checks of declared properties with a non-default value of each, causality with decisions compared up to and including the cut, every documented warning and stress scenario by an assertion, and every test that reports a p-value by a null simulation of its error rate. Escapes: E1, E2, R2-1, R3-3, R3-4, R3-5.
4. **Keep reviews small, reworded** ([GIT_GUIDELINES.md](../../GIT_GUIDELINES.md#when-reviewing), When reviewing step 6): the rule asks for large changes to be split, but #32 (11,080 lines), #51 (1,539) and #39 (1,392) were reviewed whole in full-diff rounds. The reworded rule keeps the split as the default and, when a change cannot be split, has each full-diff round review it in sittings by component and say so.

No rule is removed.
